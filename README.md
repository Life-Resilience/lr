### Brand gradient

For the **LR logo only**, we can use:

```text
#0A1F44
   ↓
#2563EB
   ↓
#06B6D4
```

But importantly, **we shouldn't turn the entire website into gradients**.

The gradient is a brand accent. The interface itself should remain mostly solid colors.

### The visual rule

**Blue = intelligence / action**
**Cyan = resilience / energy**
**Navy = trust / seriousness**
**White = clarity**

And **no neon cyberpunk aesthetic**.

This gives LR a visual language that can work equally well for the **public research website, research analytics dashboard, future cybersecurity products, and enterprise interface**.

I would treat this palette as our **working LR design system** from this point forward.
